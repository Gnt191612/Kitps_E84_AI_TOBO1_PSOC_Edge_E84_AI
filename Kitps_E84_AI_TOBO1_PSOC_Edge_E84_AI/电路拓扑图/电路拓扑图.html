七、帧协议（AA 55 + len + type + payload + XOR · 校验覆盖 type..payload）

方向type载荷说明
H7 → 84E0x0122B：cmd_type, target_id, center_angle/angle_width/min_dist/max_dist (f32), timestamp_ms识别窗口命令
84E → H70x0221B：target_id, confidence/x/y/dist/angle (f32)H7 侧 confidence<0.5 视为未识别；angle 回填命令中心角、dist 取窗口中值

八、已取消的连线（固件不再驱动 · 不要接）

  • H7 PB8 / PB9 / PB12 / PB13（旧 84E 事件通知线）与 PC1（旧 RST84E，84E 复位脚属 1.8V 域）
  • 84E P21_2 / P21_3（官方 BSP 中为 I2S，不可作 UART）、P21_4~P21_7（雷达 SPI）
  • ESP32 本地 PWM 舵机（旧 G12/G14 方案已废弃；G14 现仅作角色检测输入）

九、上电前必查与测试流程

  1. 电平转换器：1.8V↔3.3V 双向转换器必装，禁止直连；1.8V 取电位置以官方原理图为准。
  2. J5：引脚序号以官方原理图为准（尚未实物核对）；未焊接排针需自焊；勿贴 R76/R77/R79/R80。
  3. 电源空载：测外部电源电压与极性（防反接），确认舵机电源额定电流 ≥ 实测单路堵转 × 最大同动路数 × 1.5。
  4. H7 单板：USB 5V 上电，J-Link 连接；UART4 调试口出日志。
  5. 雷达：接 TRIG/ECHO（含分压），量 ECHO 脉宽 ≈ 距离 × 58µs/cm。
  6. 舵机逐只：先小范围（如 1.4/1.5/1.6ms）标定停止点与端点，逐只校准后再装整机；堵转电流未确认前禁七路同测；勿用普通万用表电流档测堵转。
  7. ESP32 单板：TTL 口 USB 供电，串口出日志，摄像头初始化确认。
  8. UART 链路：逻辑分析仪抓 AA 55 帧头（115200）；84E 链路先核电平转换器输出再接 H7。
  9. 联调：按 H7 调度时序逐级使能（雷达扫描→84E 识别→ESP32 跟踪）；实验数据按 code/EXPERIMENTS.md 采集。
