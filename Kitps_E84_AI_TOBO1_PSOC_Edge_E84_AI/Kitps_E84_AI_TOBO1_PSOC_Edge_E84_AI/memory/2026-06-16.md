## CubeMX 代码生成 + STM32H7 编译修复

### 问题
CubeMX GUI 渲染崩溃（引脚列表 PD979 溢出现象），但不影响 `.ioc` 文件配置。
CubeMX 成功生成代码后，STM32H7 工程需要重新编译。

### 编译修复项
1. **CMakeLists.txt 修改**
   - 添加 `Src/`、`Inc/` 到 include 路径
   - 链接库改为 `-nostartfiles` + `-lc -lm -lgcc`（之前 `-nostdlib` 无法链接标准库）
   - 使用 `target_link_libraries()` 确保库在目标文件后链接
   - 添加 `stm32h7xx_hal_uart_ex.c`（UART FIFO 配置需要）
   - 注释掉 `Drivers/can.c`（依赖 FDCAN HAL 但未安装）

2. **新建 `Core/init_wrappers.c`**
   - 包含 CubeMX 生成的 MX 函数体：SystemClock_Config, MX_TIM2/3_Init, MX_USART1/2/3_UART_Init
   - 包装函数：MX_UART_Init(), MX_TIM_Init()
   - 预留函数：MX_SPI_Init(), MX_FDCAN_Init(), CAN_Init()（空函数体）
   - Error_Handler() 实现

3. **实现 `ReleaseESP32()`**（在 scheduler.c 末尾）
   - 清除 ESP32 关联状态
   - 通过 Protocol_SendESP32Command 发送释放命令（cmd=0x02）

4. **LD 脚本修改**
   - 添加 `PROVIDE(_end = .)`（sysmem.c 的 _sbrk 需要）
   - 添加 `PROVIDE(_estack = ...)`（newlib 堆管理需要）
