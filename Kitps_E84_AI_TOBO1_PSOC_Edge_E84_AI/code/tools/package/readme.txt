多目标跟踪系统 3D 仿真

打开方法
  Windows：双击“启动3D仿真.bat”。
  macOS / Linux：用 Chrome 或 Edge 打开 sim_3d.html。

环境要求
  只需要 Edge 或 Chrome（Windows 10/11 自带 Edge）。不需要联网，也不需要安装其他软件。
  如果提示无法启用 3D，请在浏览器设置里打开“使用图形加速”。

可以做什么
  实时仿真：不接硬件，真实的 H7 固件在软件里运行。可以换场景、拖动人和物品、拔线、改模型参数，
            看三块板的相机画面、发现时间、跟踪情况和舵机角度；批量统计可对照项目指标。
            传感器和环境是模型，参数未经实物校准，数字不代表实物性能。
  舵机供电：默认是接线方案（自制电源分配板，电源 3 A）。在“仿真”页可切到面包板对比，也可改电源电流，
            看电压、停转和跟踪效果。舵机电流和线路压降都是估计值，要用实测值替换。
  回放样例：回放一段录好的完整流程。
  点引脚或导线：查看它连到哪里。“连线”页可以搜索引脚，如 PB6。
  连接串口：USB-TTL 接 H7 的 UART4（PC10/PC11，921600），实时显示并可发送命令。
  手动调试：拖动云台和虚拟人，计算云台所需角度。
  安装：填入实测位置，生成 config_mount.h 代码。
  demo_monitor.html：答辩用的二维监控界面。

注意
  H7（鹿小班 LXB743ZI-P1）外形已按宣传图校正，但引脚名在排针上的位置仍是按编号排的，接线以实物丝印为准。
  外形和尺寸按照片估计。接线以项目的 code/WIRING.md 为准。
