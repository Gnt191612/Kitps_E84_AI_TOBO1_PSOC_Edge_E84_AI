## 怎么用

- **Windows：** 下载 `Sim3D-Windows.exe`，双击即可，自动安装到当前用户目录，创建桌面快捷方式并打开软件。不需要管理员权限，也不需要联网。
- **免安装或 macOS / Linux：** 下载 `Sim3D-Portable.zip`，解压后双击“启动3D仿真.bat”，或用 Chrome / Edge 打开 `sim_3d.html`。macOS 和 Linux 尚未测试。

只需要 Edge 或 Chrome（Windows 10/11 自带 Edge）。

> 安装程序没有数字签名，Windows 可能提示“已保护你的电脑”，点“更多信息”→“仍要运行”。

内置仿真是电脑上的仿真，不是实物数据。H7 排针的物理位置未核对，接线以实物丝印和 `code/WIRING.md` 为准。
