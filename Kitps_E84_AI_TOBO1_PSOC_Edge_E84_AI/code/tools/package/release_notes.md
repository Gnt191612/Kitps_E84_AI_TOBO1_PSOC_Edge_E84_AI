## 怎么用

**推荐：免安装版。** 下载 `Sim3D-Portable.zip`，全部解压到一个文件夹，双击“启动3D仿真.bat”。不能在压缩包里直接运行。

macOS / Linux 用 Chrome 或 Edge 打开解压后的 `sim_3d.html`（尚未测试）。

**安装版。** 下载 `Sim3D-Windows.exe` 双击，安装后按提示打开。它没有数字签名，Windows 可能提示“已保护你的电脑”（点“更多信息”→“仍要运行”）；装有火绒等安全软件时，可能无法建快捷方式或自动打开，这时请用免安装版。

只需要 Edge 或 Chrome（Windows 10/11 自带 Edge），不需要联网和管理员权限。

“实时仿真”运行真实的 H7 固件，但超声波、舵机、84E、ESP32 和房间都是模型，参数未经实物校准，数字不代表实物性能。H7 排针的物理位置未核对，接线以实物丝印和 `code/WIRING.md` 为准。
